# Il·lustracions Glass Rooms

Vuit il·lustracions vectorials originals creades per a aquest projecte. Representen interiors conceptuals: no són plànols de l’habitatge i no indiquen la ubicació de cap dispositiu.

- Format SVG, `viewBox="0 0 400 270"`, fons exterior transparent.
- Paleta comuna: lli, pedra, fusta, sàlvia i terracota.
- Geometria vectorial i degradats lineals simples; sense fonts, scripts, filtres, imatges externes ni dependències de xarxa.
- Cada fitxer inclou un títol i una descripció accessibles en català.

## Llicència

Aquests recursos originals es poden utilitzar, copiar, modificar i redistribuir lliurement, inclòs per a ús comercial, sense atribució obligatòria. Es proporcionen sense garantia. No contenen recursos de tercers.
